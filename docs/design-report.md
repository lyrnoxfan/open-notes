# 界面重做报告

任务只有一件：把已经能用的应用做得好看看。功能、加密、备份、测试全部没动，动的只有界面层。

- 设计规格：`docs/design.md`（颜色、字阶、间距、圆角、细线、图标、动效、对比度、无障碍）
- 对比度脚本：`scripts/contrast.py`，由 CI 里的 `DesignTokenContrastTest` 兜底
- 字体子集脚本：`scripts/subset-font.sh`
- 预览：`app/src/main/java/com/example/privatenotes/ui/preview/Previews.kt`

## 1. 按任务编号

### 1) 字体
- 打包霞鹜文楷 Regular 子集：GB2312 一二级 + ASCII + 中文标点 + 全角符号，3.29 MB。
  `GSUB/GPOS/vhea/vmtx` 去掉——应用只排横排、不做自绘字距。
- OFL 1.1 许可放进 `assets/licenses/`，设置页「关于」可查看全文。
- `Type.kt` 补齐 Material 3 全部 15 个样式。原来只有 7 个，`labelMedium` 缺失，
  胶囊标签因此回退到 Roboto，和整页字号对不上。
- 衬线用于正文/标题/预览，无衬线用于按钮、胶囊、时间戳、状态。12–13sp 上楷体笔画会糊，
  参考站本身也是正文衬线、元信息无衬线。
- 缺字回退系统字体，生僻字与 emoji 不会是豆腐块。

### 2) 笔记列表
- 删除改成左滑 + 撤销条；每行常驻的垃圾桶图标去掉。行宽全部让给文字，误触也毁不掉东西。
  同一动作以 `customActions` 暴露给 TalkBack 与开关控制。
- 时间戳按人想事情的方式显示：今天给时刻、今年给月日、更早给年月日。
- 搜索框：`surface` 底 + 1dp `dividerStrong` 细线，有内容时细线转强调色。
- 标签胶囊：页面底色 + 细线，只有当前筛选被填充。
- 新建按钮压平：强调色底、`onAccent` 图标、零高度阴影、圆形。
- 空状态一句话。没有插画。
- 应用锁对话框原来在同一个界面里被渲染两次，叠了两层；现在只声明一次（后续并入设置页）。
- 版心 680dp 居中。

### 3) 编辑页
- 横向跳位的真正原因是内边距：Material `TextField` 自带约 16dp 内边距，预览 `TextView` 没有。
  两端都换成无内边距的 `BasicTextField` / 零 padding 的 `TextView`，共用同一套 24dp 页边、
  同一个宽度上限、同一组字体，切换时 150ms 交叉淡入淡出。
- 标题与正文都是 `BasicTextField`：无内边距、无下划线、光标与选区用强调色。
- 标签胶囊与列表筛选胶囊同款。
- 删除移进「更多」，配垃圾桶图标和错误色——整页唯一的破坏性动作。

### 4) Markdown 预览
- Markwon 的每一项主题值都来自 `MaterialTheme`：衬线标题与正文、等宽代码、强调色下划线链接、
  引用左侧竖线用 `accentContainer`、分割线 1dp `outlineVariant`。
- 行距由 `bodyLarge` 的行高算出来（17sp/30sp），不再写死 1.25。
- 预览可滚动。原来长笔记到屏幕底部就没了。
- 首行基线与编辑态对齐（补同样的半行距、其余 padding 归零）。
- 链接可点，因此不能同时开启文本选择——Android 会换上吃掉点击的 movement method。
  需要复制时走编辑态。

### 5) 设置页 + 关于
- 六个分区，顺序固定：应用锁 / 本地备份 / WebDAV / 导入 / 备份状态 / 关于。
- 分区是「衬线小标题 + 1dp 细线 + 内容」，没有卡片、没有阴影、没有底色块。
- 应用锁成为正式设置项，规则不变（设备没有安全锁屏时拒绝开启，并给出系统设置入口），
  旧对话框删除；列表的「更多」菜单只剩这一项，一并删掉。
- 备份状态独立成区，两个目的地上下相邻：成功一行，最近失败一行加原因。
- 关于：版本号、正文字体与许可（点开读 assets 里的原文）、一句加密说明。

### 6) 回收站 + 锁屏
- 锁图标从 76dp 色块换成一个 28dp 线性图标，层级交给 12sp 应用名、22sp 衬线标题、15sp 副标题。
- 回收站行与列表共用页边与 1dp 细线；「恢复」用强调色、「永久删除」用错误色，同为文字动作。
- 两处空状态都是一句话。

### 7) 深色模式与对比度
- `values-night/colors.xml` 只负责首帧窗口底色（`#1C1410`，深暖棕，不用纯黑）；之后 Compose 接管。
- Material 的全部颜色角色都做了映射（container、inverse、`outline` 与 `outlineVariant` 分工）。
  未映射的角色会退回 Material 的灰阶，在暖纸页面上是一块冷色。
- 占位文字的 70% 透明度去掉：深色下会掉到 4.5:1 以下。
- 对比度数字见第 3 节，全部达标。

### 8) 大字号与小屏
- 编辑页标签胶囊改成 `FlowRow` 换行（实机 2.0 倍字号下 alpha/beta 一行、gamma 第二行）。
- 回收站两个动作在 2.0 倍下换行。
- 锁屏可滚动：原来 2.0 倍字号解锁按钮会被挤出屏幕。
- 设置页权重按钮允许两行；顶栏标题锁一行加省略号。

### 9) 动效
- 只有两档：150ms（页面交叉淡入、编辑/预览切换）、180ms（列表项进出与位移）。
- 页面切换去掉默认的滑动转场，改用淡入——一个安静的页面不该有两种运动语言。
- 系统开启「移除动画」时自动跳过。

### 顺手修掉的一个既存缺陷

第一次跑设备套件时 `AppLockIntegrationTest.returningAfterMoreThan30SecondsRequiresAuthentication`
稳定失败在 `assertFalse(isDatabaseOpen)`：锁屏确实关掉了数据库，但随后又被重新打开。
入口只有一个 —— `AppContainer.database`：锁定落下时仍在运行的读取（列表查询的
`WhileSubscribed` 窗口、刚好启动的备份 worker）会从那里把连接再开一次。

重做界面让首帧变慢，把这个偶发竞态变成了必现，所以它是在这次改动里被发现的。
修法是在那个唯一入口加守卫（取连接前查一次、进入开连接的临界区再查一次）：锁定时拒绝打开。
解锁后的行为不变，仍然是懒打开、解锁后重开。修复后该类测试通过，完整套件 31/31 绿。

## 6. 需要决策

1. **正文到底用哪套衬线。** 任务里说参考站正文是霞鹜文楷，但 blog.lyrnox.com 现在的
   `--serif` 是 `"Noto Serif SC","Source Han Serif SC","Songti SC",…`，即宋体一路，不是楷体。
   我按任务要求打了霞鹜文楷（楷体，手写味更重）。如果你要的是博客那种印刷宋，换
   `Type.kt` 里的一行字体资源即可，`subset-font.sh` 换个上游文件就能重做子集。
2. **字体超预算 0.79 MB。** 观察结果：APK 增量 2.04 MB，仍在预算内；字表完整则不会出现
   生僻字回退成黑体的跳字。若坚持 2.5 MB，把脚本里的字表切到一级字（1.67 MB）。
3. **博客色值与 DesignTokens 有出入。** 博客当前浅色底是 `#F1E7DA`、强调色 `#A13F04`，
   与 DesignTokens 一致；博客另有 `#fffaf3`、`#ece1cc` 等辅助色，我没有引入，避免色板膨胀。
4. **预览不能选中文本。** 为了链接可点，必须放弃 `setTextIsSelectable`。要复制请回编辑态。
   若更看重复制，可以反过来牺牲链接点击。
5. **`dividerStrong` 只有 1.68:1。** 输入框边界按 WCAG 1.4.11 的严格读法应到 3:1；那样会得到
   一条很重的深棕线，与「暖纸、细线」的基调冲突。现在靠底色差 + 搜索图标 + 占位文字共同暗示
   输入区。要严格合规就把它调到 3:1，观感会更像表单。

## 7. 请在手机上看的 6 件事

1. **编辑 ↔ 预览切换**：第一行字、左边距、行距是否纹丝不动。这是本次最容易翻车的点，
   模拟器上量到两端原点都是 (66, 562)，但真机字体度量可能略有差别。
2. **列表左滑删除 → 撤销**：手感是否顺，撤销条会不会被 FAB 挡住。
3. **正文字体观感**：17sp 霞鹜文楷在 ColorOS 上是否偏小/偏细；长文连续读五分钟累不累。
4. **深色模式**：深暖棕底 + 暖橙强调，是否还留有「纸」的感觉，分割线会不会看不见。
5. **2.0 倍系统字号**：列表、编辑页、设置页、锁屏是否都能滚到底、按钮不被挤掉。
6. **设置页「关于」**：版本号、字体许可（点开读全文）、加密说明是否读得通。
