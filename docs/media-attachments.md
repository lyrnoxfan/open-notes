# 图片与视频附件（本地候选，尚未设备验收）

现有编辑器加入“添加图片”“添加视频”。系统文件选择器只用来读取所选文件；导入时复制到本地 SQLCipher，之后离线可用，不依赖原文件 URI 授权。附件显示在独立附件区；点击进入应用内看图、缩放或视频播放，可确认后移除。正文 Markdown 不变，不是富文本正文内嵌编辑器。

## 范围与容量

- 图片 JPEG、PNG、WebP、GIF：单个最多 8 MiB，GIF 静态预览；按尺寸采样解码，最长边约 2048 像素预览。
- 视频 MP4、WebM、3GP：单个最多 256 MiB，实际播放取决于设备解码器；支持播放/暂停、进度拖动、离开前台暂停。
- 每篇最多 10 个附件、合计 512 MiB。导入逐块写入，不把完整视频复制为 ByteArray 或 Base64。输入中断、超限、无空间和取消抛错会使同一数据库事务回滚。
- 附件与元数据保存在 SQLCipher；每个载荷行最多 256 KiB，避免 CursorWindow 大行。视频播放前逐块核对 SHA-256，随后按需随机读取，仅缓存一个解密块。无明文临时媒体文件、外部播放器或导出 provider；窗口保留 secure 标志。
- 不压缩或转码原件，不提供拍摄/录制、网络媒体下载。导入和加密备份可能较慢，期间保持应用前台；锁定关闭数据库时操作会失败，不承诺后台完成。
- 回收与恢复保留附件；永久删除级联清理媒体和分块。正文保存不会替换附件，添加/移除更新修改时间及现有备份调度。

## 旧数据与备份兼容

- Room 1→2 新增媒体表和分块表，非破坏性迁移；保留 v1/v2 schema。
- 仍读取旧 schema 1 JSON/PNB；旧备份更新正文不会抹除本地附件。
- 普通 JSON/PNB 使用 schema 2 和 Base64/哈希字段，仍有单附件 8 MiB、媒体合计 40 MiB、文件 64 MiB 的原有内存安全上限。超限会明确失败并提示用“大媒体加密备份”，不生成漏图/漏视频的假完整备份。明文 JSON 的媒体也是明文。
- 设置页新增“大媒体加密备份”，手动导出/恢复 `.pnm`，媒体合计最多 2 GiB，文字元数据最多 16 MiB。此格式逐块写入与读取，不 Base64 视频；密码至少 8 个字符、不保存、没有找回方式。旧版应用不能读取 `.pnm`。
- PNM 头 `PNMEDIA3`，PBKDF2-HMAC-SHA256 210000 次派生 AES-256；随机盐与随机 nonce 前缀，每条记录用递增索引产生唯一 nonce，AES-GCM 认证头/索引。记录上限 256 KiB，包含终止标记并拒绝尾随数据。逐附件 SHA-256 及尺寸/格式再校验；截断、篡改、密码错误及数据库写失败都会回滚整次恢复。
- PNM 恢复采用现有合并/删除标记策略，保留较新本地笔记，等时间差异报告为冲突。不是无条件覆盖现有库。
- 导出直接写系统文档提供者的加密文件，不产生明文暂存。失败时尝试删除新建的未完成文件；第三方文档提供者可能不允许删除，失败文件不可当备份。
- 大媒体 PNM 暂仅本地手动入口；自动备份/WebDAV 保持旧格式和上限，不能自动备份包含大视频的库。不要依赖失败的自动备份，使用新入口手动导出并验证恢复。

## 验收

`./gradlew --no-daemon testDebugUnitTest assembleDebug assembleDebugAndroidTest lintDebug`

Robolectric/单元覆盖迁移、分块读写/随机播放源、保存与回收删除、旧 JSON/PNB 往返、旧备份保留附件、冲突及重复 ID 回滚。新增 48 MiB 合成容量载荷（不是可播放影片）验证大于旧 8/40 MiB 上限的流式导入、加密归档、恢复及完整哈希；测试中断流、取消、模拟磁盘写失败、图片超限、错误密码、篡改、截断与尾随数据恢复回滚。容量测试不是 Android 真机内存/播放器验收，不代表已实测 256 MiB/2 GiB 最大边界。

`MediaDeviceTest` 是独立 ScriptDriven 设备测试，接入现有 API26/API35 CI：真实 SQLCipher v1 迁移、12 MiB 合成容量归档恢复及截断回滚、真实 PNG 显示、ffmpeg 合成 MP4 播放计时和加密备份恢复。设备测试 APK 编译不等于断言通过；系统文件选择器、OEM 解码器、锁屏/前后台交互及文件提供者行为仍需设备验证。

## 交付边界

候选只在本地 `feature/photo-video`；未推送、创建 PR、合并、发布或更改签名。完整本地构建及设备启动记录见交付验证报告；如当前环境无法启动设备，须得到仅推送分支/创建 PR 的授权后，才能运行现有 API26/API35 CI。未经设备验收不得称正式完成，也不能拿 Debug 包替代正式签名 Release。
